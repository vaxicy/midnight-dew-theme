# Changelog

## 1.0.0

- Initial release of Midnight Dew Theme.
- Adds `Midnight Dew Theme Light` and `Midnight Dew Theme Dark`.
- Full workbench theming: editor, sidebar, activity bar, tabs, panels, status
  bar, terminal, diffs, widgets, and notifications.
- Syntax palette covering comments, strings, numbers, keywords, types,
  functions, variables, properties, tags, attributes, and Markdown.
- Extension icon and store preview screenshots.
